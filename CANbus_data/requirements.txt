# Python dependencies for the CANbus_data tools on a Windows PC.
# (On the Raspberry Pi use requirements-pi.txt instead -- SocketCAN
# needs no USB packages.)
# Recreate the environment on a new PC:
#
#   py -3.12 -m venv C:\projects\solar_car\venv
#   C:\projects\solar_car\venv\Scripts\python.exe -m pip install -r CANbus_data\requirements.txt
#
# Built and tested against Python 3.12.10 on Windows.
#
# Top-level packages this project actually imports:
#   python-can      - CAN bus library / ASC logging
#   pyserial        - serial backend for python-can's slcan interface (the
#                     SH-C31G runs slcan firmware -> a serial port). DEFAULT path.
#   gs-usb          - direct gs_usb adapter access (only if reflashed to gs_usb)
#   pyusb           - USB backend for gs_usb
#   libusb-package  - bundled libusb backend (no system install needed)
#   PyMuPDF         - PDF text extraction (spec tooling)
#   paramiko        - SSH to the Home Assistant host (ha_push.py / ha_run.py)
# The rest are pinned transitive dependencies.
